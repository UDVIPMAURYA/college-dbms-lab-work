# College DBMS Lab Work

AKTU B.Tech 5th Semester — Database Management Systems Lab (BCS551 / KCS551)

## About
Practical implementation of the full DBMS Lab syllabus using Oracle Database 21c XE,
organized module-wise. Beyond the lab manual, concepts are extended to match the
depth expected in interviews and AKTU exams.

## Tech Stack
- Oracle Database 21c XE
- Oracle SQL Developer
- PL/SQL

## Structure
| Module | Contents |
|---|---|
| module-1-setup-er-design | Installation, first SQL command, ER diagram |
| module-2-sql-core | DDL, DML, DQL, Joins, Aggregates, Views, Indexes, DCL, TCL |
| module-3-normalization | 1NF, 2NF, 3NF, BCNF |
| module-4-plsql | Blocks, Cursors, Procedures, Functions, Packages, Triggers |
| module-5-real-systems | Payroll, Library, Student Information System |
| module-6-backup-recovery | Backup and recovery concepts |
| module-7-mini-project | Complete standalone mini project |

## Course Outcomes Covered
- CO1: Oracle objects (tables, views, indexes, sequences)
- CO2: Database schema design for real systems
- CO3: DDL/DML/DCL/TCL queries
- CO4: PL/SQL — procedures, functions, packages, triggers, cursors
- CO5: Entity, referential, key and domain integrity
